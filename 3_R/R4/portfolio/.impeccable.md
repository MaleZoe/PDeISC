## Design Context

### Users
Diego Ramírez — propietario del portfolio. La audiencia son recruiters, empresas y clientes freelance que buscan conocer su perfil como desarrollador. Visión: mostrar versatilidad técnica con criterio estético.

### Brand Personality
Enfocado · Curioso · Creativo. Developer que construye con diseño y propósito.

### Aesthetic Direction
Dark cinematográfico inspirado en Prisma (motionsites.ai). Fondo negro cálido `#0c0b09`, texto cream `#edeadb`, acento ámbar `#c8903a`. Tipografía editorial con Bricolage Grotesque (display) + Figtree (body). Animaciones con Framer Motion: word pull-up, scroll-linked character reveal, staggered card entrance.

### Design Principles
1. **Tipografía como protagonista** — el nombre llena el viewport, jerarquía visual clara.
2. **Dark con calidez** — negro con tinte cálido, nunca frío ni azulado.
3. **Editorial, no genérico** — skills como tabla tipográfica, no icon grids.
4. **Animación con propósito** — solo donde refuerza jerarquía o narración.
5. **Craft visible** — que se note que el dev tiene criterio visual, no solo técnico.
