# Proyecto R1 - Colección de Ejercicios

Este directorio contiene una serie de proyectos (Proyecto 1 al Proyecto 6) desarrollados como parte del módulo R1.

## Estructura del Repositorio

- **Proyecto 1 a 6**: Contienen aplicaciones React (Frontend) y en algunos casos integraciones de backend con Express y bases de datos SQLite (`server`).
- **Tecnologías utilizadas**: React, Vite, Express, Node.js, SQLite, Bootstrap.

## Ejecución de los Proyectos

Cada subcarpeta (`Proyecto X`) contiene sus propios archivos de configuración. Por lo general, cada uno sigue esta estructura:

1. Navegar a la carpeta del proyecto específico (por ejemplo, `cd "Proyecto 6/client"` o `cd "Proyecto 6/server"`).
2. Instalar dependencias con `npm install`.
3. Ejecutar en modo desarrollo con `npm run dev` (para Vite/Frontend) o iniciar el servidor backend según corresponda.

> **Nota**: Este documento sirve como índice general para los distintos ejercicios realizados en la etapa R1.
